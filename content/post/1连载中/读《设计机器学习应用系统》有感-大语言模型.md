## 语言模型的奇点

> 摒弃了神经网络，只使用注意力机制解决记忆与依赖问题。



### Transformer架构



#### 循环依赖到注意力机制

- RNN的性能问题

1. 传统LSTM的模型局限于序列的循环依赖。时刻t的计算必须等待时刻t-1完成，应为t的输入要包含上一个时刻的隐藏状态。RNN的序列依赖设计天然阻止了并行计算，迫使GPU串行执行，严重浪费了资源。
2. 长距离信息衰减，当循环次数足够多，会导致信息完全失效。



- Bahdanau注意力机制

编码器不变，依然将输入序列编码为一系列隐藏状态，解码器在时刻 t*t* 的隐藏状态 st*s**t* 会计算与此前每一个编码器隐藏状态的对齐得分，然后通过 Softmax 归一化得到注意力权重，再加权求和得到最终的上下文向量 。

![1793778955711.png](https://fastly.jsdelivr.net/gh/thecoolboyhan/th_blogs@main/image/2026-11/1793778955711_1793778955748.png)

1. 维度灵活：可以有不同的输入维度
2. 非线性建模能力：tanh激活函数允许模型学习到更复杂的对齐模式。
3. 三个参数矩阵都是可学习的，模型可以通过训练自动发现最优额度对齐策略。

> 这种注意力是交叉注意力，编码器和解码 内部还是LSTM在处理序列依赖，编码过程仍然是串行的。后面Transformer完全放弃了 LSTM 或 GRU实现了真正的并行化。



- 自注意力

![1793780067042.png](https://fastly.jsdelivr.net/gh/thecoolboyhan/th_blogs@main/image/2026-11/1793780067042_1793780067084.png)

> 交叉注意力的信息流向：解码器提供查询，编码器提供键和值，两者交叉相关，输出两个序列之间的对话协商的结果。

![1793780459704.png](https://fastly.jsdelivr.net/gh/thecoolboyhan/th_blogs@main/image/2026-11/1793780459704_1793780459745.png)

> 都在同一个序列里，不依赖解码器和编码器，所有位置都可以看到其他位置，能够直接建立关联。

每个位置同时计算， 然后关联根据权重交叉出结果。没有信息的层层传递。



#### Transformer组件

> Transformer架构的组成部份

- 多头注意力

并行运行多个独立的单头注意力，每个头学习不同的关注模式，最后将所有头拼接起来，让模型能从多个角度观察序列。



- 前馈神经网络（FFN）

FFN 是一种与 RNN 相对的网络概念，强调信息向前流动无反馈链接。

第一层将输入投影到高维空间，每个隐藏神经元可以学习识别一种特征组合，ReLU 激活那些匹配的模式。第二层将激活的模式组合回输出空间。



- 残差连接

> 当Transformer堆叠的层数足够多，信息从输入的输出层需要变化上百次。每次变化都可能导致梯度消失和爆炸，深层参数难以有效更新。



残差连接将子层的输入直接加到输出上，让网络学习残差关系，而非完整的映射关系。梯度可以通过残差路径直接传递，不需经过子层的复杂变换。

每次的信息输入都包换了原始输入信息，即使经过多层变化，信息也不会完全丢失。



- 层归一化

将每个位置额度特征归一化到相似的数值分布范围中。批归一化在批次维度上统计均值和方差，层归一化在特征维度上进行统计。

#### 组装Transformer模型



**多头自注意力**：负责信息收集，从序列中提取全局依赖关系，决定“看哪里”。

**前置神经网络**：负责信息加工，对收集到的信息进行语义理解和转化，决定“看懂是什么”。

**残差连接**：负责信息传递，保证梯度流畅，避免深层网络的训练困难，决定“能构建多深”。

**层归一化**：负责数值稳定，控制每层的输出分布，避免训练崩溃，决定“能否成功收敛”。

![1793784443220.png](https://fastly.jsdelivr.net/gh/thecoolboyhan/th_blogs@main/image/2026-11/1793784443220_1793784443247.png)

输入向量首先进入注意力子层，多头自注意力从序列中收集全局信息，然后进入前馈子层，前馈神经网络对信息进行语义加工，残差连接保留原有表示。最终输出与输入形状相同，保证了多个这样的编码器层可以重复堆叠。

![1793784595244.png](https://fastly.jsdelivr.net/gh/thecoolboyhan/th_blogs@main/image/2026-11/1793784595244_1793784595264.png)

| 特性         | 编码器层               | 解码器层                                |
| :----------- | :--------------------- | :-------------------------------------- |
| 自注意力类型 | 双向自注意力           | 因果自注意力                            |
| 额外注意力   | 无                     | 编码器 - 解码器交叉注意力               |
| 子层数量     | 2 个（自注意力 + FFN） | 3 个（因果自注意力 + 交叉注意力 + FFN） |
| 信息来源     | 仅输入序列             | 输入序列 + 编码器输出                   |
| 典型任务     | 理解任务（BERT）       | 生成任务（GPT）                         |
| 代表模型     | BERT                   | GPT                                     |

![1793784743649.png](https://fastly.jsdelivr.net/gh/thecoolboyhan/th_blogs@main/image/2026-11/1793784743649_1793784743667.png)



- 常见的发展路线

| 特性       | BERT（编码器路线） | GPT（解码器路线）  | T5（编码器-解码器路线）     |
| :--------- | :----------------- | :----------------- | :-------------------------- |
| 注意力类型 | 双向（看左右）     | 单向（只看左边）   | 编码器双向 + 解码器单向     |
| 预训练目标 | MLM（填空）        | CLM（续写）        | Span Corruption（跨度破坏） |
| 核心能力   | 理解               | 生成               | 理解 + 生成                 |
| 典型任务   | 分类、标注、问答   | 文本生成、对话     | 翻译、摘要、问答            |
| 代表模型   | BERT、RoBERTa      | GPT、LLaMA、Claude | T5、mT5、BART               |
